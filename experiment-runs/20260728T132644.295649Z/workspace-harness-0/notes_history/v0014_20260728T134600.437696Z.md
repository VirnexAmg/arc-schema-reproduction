# Working notes

## Grounded objects
- Main playfield is a 5-pixel lattice maze: color 3 is traversable corridor; color 4 is wall/exterior.
- Movable 5x5 token has color 12 in its top two rows and color 9 in its bottom three.
- Rows 61-62 are a 42-step attempt strip.
- The branch cell at x=19,y=30 contains a reusable embedded 0/1 glyph hidden by the token while occupied.
- The framed color-5/9 pattern near x=32..40,y=8..16 is a target/display terminal.
- Lower HUD rows 55-60 encode a 3x3 binary register.

## Established mechanisms
- ACTION1=up, ACTION2=down, ACTION3=left, ACTION4=right.
- Legal actions shift the token by one 5-pixel cell; walls block.
- Vacating the marker restores its glyph; some entries transform the HUD.
- Full timeline of 58 checked transitions backtests exactly.
- At terminal x=34,y=15, ACTION1 is an inert submission attempt when the register is wrong; ACTION3 is a consuming wall collision.
- Meter exhaustion causes the following action to reset token, meter, HUD to 111/100/101, and status lamps.

## Current observation
- First fresh marker entry changed 111/100/101 -> 111/001/101.
- Second entry changed that to 101/001/111.
- Third entry was inert: HUD remains 101/001/111. Token is on marker x=19,y=30 with 33 meter columns remaining.
- Target is 111/010/101, so current HUD is not equal.

## Competing hypotheses
- H1: marker activation has a multi-entry phase schedule and the third entry is deliberately inert; a later entry may continue the sequence.
- H2: marker applies a local transformation only when some register precondition holds; 101/001/111 is now a fixed point until another object/status changes.
- H3: activation depends on approach direction or a hidden status bit rather than entry count alone.
- Literal target equality remains the strongest submission hypothesis.

## Ruled out
- Meter exhaustion preserves neither assembled HUD nor phase.
- Up at terminal does not submit an incorrect HUD.
- A simple transform-on-every-entry cycle is false because the third entry was inert.

## Needs testing
- Vacate left and re-enter right a fourth time to distinguish a delayed phase schedule from a fixed point.
- Test alternate marker approach if repetition remains inert.
- Derive operations from glyph/status lamps rather than meter-coordinate thresholds.
