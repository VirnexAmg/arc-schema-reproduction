# Working notes

## Objects
- Movable 5x5 token: color 12 on top two rows, color 9 on bottom three.
- Color-3 corridors and color-5 chamber floor are traversable; color 4 is wall.
- A 0/1 control glyph lies in the left branch and can be covered by the token.
- Upper color-9 motif is the likely target.
- Bottom-left 9-pattern is a directional control-status indicator.
- Two-row color-11 strip is a movement budget.

## Established mechanisms
- Movement is 5 pixels: ACTION1=up, ACTION2=down, ACTION3=left, ACTION4=right.
- Ordinary successful and blocked moves consume one budget column.
- Crossing the control changes the bottom status pattern.

## Mismatch revision
- The latest historical ACTION2 crossing changes status to the downward pattern but does not consume budget. This falsifies the prior rule that a downward return after an upward crossing is charged.
- Attempts to infer the refund from status or nearby wall landmarks have not yet affected the replay mismatch; likely the status-update branch and budget branch need to be coupled directly rather than independently re-detecting the event.

## Goal hypothesis
- Activate the status matching the upper motif by crossing downward, then use the outer loop to approach the target without reversing across the control.
